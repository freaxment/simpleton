Simpleton by Freaxment — VST3 / AU
macOS (Apple Silicon + Intel) и Windows (x64)

=== УСТАНОВКА: macOS ===
1. macOS/VST3/Simpleton.vst3     -> ~/Library/Audio/Plug-Ins/VST3/
   macOS/AU/Simpleton.component  -> ~/Library/Audio/Plug-Ins/Components/   (AU: Logic, Ableton, FL Studio)
   Папка ~/Library скрыта: в Finder нажми Cmd+Shift+G и вставь путь.
2. Плагин не нотаризован Apple, поэтому macOS может его заблокировать. Один раз выполни в Терминале:
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Simpleton.vst3 ~/Library/Audio/Plug-Ins/Components/Simpleton.component
3. Пересканируй плагины в DAW.

=== УСТАНОВКА: Windows ===
1. Windows/Simpleton.vst3 (вся папка) -> C:\Program Files\Common Files\VST3\
2. Пересканируй плагины в DAW (Ableton: Options > Plug-Ins > Rescan; FL Studio: Plugin Manager > Find plugins;
   Bitwig: Settings > Plug-ins).

=== УПРАВЛЕНИЕ ===
Volume: 0 % тишина, середина 0 dB, максимум +10 dB.
Width:  0 % mono, 100 % без изменений, 300 % side x3.
Mute / Mono. Двойной клик по ручке возвращает середину. Правый клик по фону: выбор скина Minimalist / Flex.

=== INSTALL (EN) ===
macOS: copy macOS/VST3/Simpleton.vst3 to ~/Library/Audio/Plug-Ins/VST3/ and macOS/AU/Simpleton.component to
~/Library/Audio/Plug-Ins/Components/. The plugin is not notarized, so run once in Terminal:
  xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Simpleton.vst3 ~/Library/Audio/Plug-Ins/Components/Simpleton.component
Windows: copy the whole Windows/Simpleton.vst3 folder to C:\Program Files\Common Files\VST3\
Then rescan plugins in your DAW. Right-click the plugin background to switch between the Minimalist and Flex skins.
